# editor-ia-starter-kit

Short-form video editing (Reels, Shorts) with Claude Code and HyperFrames.
Footage goes into `inbox/`, finals come out of `outbox/`.

## 0. First run

If `node_modules/` or `.env` is missing, or `npx hyperframes doctor` fails, the
kit is not installed. Walk the user through `docs/SETUP.md` in their language
before anything else. Setup creates no projects and no example videos.

## 1. Identity

Claude Code only. Read `kit.config.json` at the start of every task: it sets
the language, the model profile, the transcription provider, the default brand
and the delivery contract. Speak to the user in `language` (default `es`).
Skills, docs and code stay in English.

## 2. Folders

- `inbox/`: the user drops footage, audio and references here, unsorted. At
  project start run `node scripts/inbox.mjs`, propose which files belong to the
  project, and move them after the user confirms.
- `video-projects/<yyyy-mm-dd>-<slug>/`: all work in progress. `raw/` holds the
  moved sources. `project.json` is the truth about the project. Run HyperFrames
  from this folder.
- `outbox/<project-id>/`: finals only. Every project ends here with a video and
  a cover, plus `caption` and `srt` by default. `node scripts/deliver.mjs`
  enforces the contract.
- `brands/<slug>/`: one folder per client: `DESIGN.md`, `tokens.css`, `fonts/`,
  logo. A project names one brand in `project.json`; read that brand only.
  Another brand's files stay closed for this project.
- `styles/drafts/` and `styles/core/`: editing styles reverse-engineered from
  reference videos. Any brand can use any style. The user promotes to core.
- `PROJECTS.md`: generated by `npm run projects`. Edit `project.json` instead.

Create a project with `npm run new-video -- <slug> --brand <brand> --mode guided|freeform`.
Keep raw files intact and write each editing stage to a new filename.
Keep secrets and private media out of the kit's examples and styles.

## 3. Models

Claude Opus 5.5 owns taste: story, cuts, graphics, sound.
Profile `solo` (default): one Opus agent does everything.
Profile `team`: Opus orchestrates and decides; Claude Haiku 5.5 subagents run
mechanical parallel work only (transcripts, probes, validators, contact sheets).
Switch to `team` when the user says usage is low. Fable is outside this kit.

## 4. Map

The front door is `/new-video`. It asks one question: guided or freeform.

Guided is the known path: the editing playbook and its gates.

| Need | Skill |
| --- | --- |
| Start any video: mode, brand, project, footage | `new-video` |
| Reel, Short, short ad from footage | `short-form-edit` |
| Full raw-video edit, long form | `edit-video` |
| Silence removal | `cut-silences` |
| Retakes, false starts, stutters | `cut-mistakes` |
| Brand reel cut to music, intros | `motion-showreel` |
| Motion-graphics video from a brief, no footage | `make-a-video` |
| Video from a website (browser pane capture) | `website-to-hyperframes` |
| Narrative arc, persistent world | `video-storytelling` |
| Overlay beats, glass cards, paper takeovers | `hyperframes-video-beats` |
| Pick or extend motion-graphics cards | `style-library` |
| Apply a reverse-engineered editing style | `apply-style` |
| Turn a reference video into a new style | `reverse-engineer-style` |
| Put finals in the outbox | `deliver` |
| HTML compositions and media timing | `hyperframes` |
| Preview, lint, render, transcribe | `hyperframes-cli` |
| Timeline animation | `gsap` |
| Install HyperFrames catalog blocks | `hyperframes-registry` |

Freeform has no workflow and no gates: the user drives, you suggest and try.
Same tools. The delivery contract still applies.

Before creative work read `MOTION_PHILOSOPHY.md`, the brand's `DESIGN.md` and
the project's `DESIGN.md`. The brief wins over the brand; the brand wins over
the kit's defaults.

Transcription: `npx hyperframes transcribe <video>` (local Whisper), then
`node scripts/whisper-to-kit.mjs` to get the `raw.json` shape the cutting tools
read. `elevenlabs` in the config switches to `npm run transcribe`. Without
`ELEVENLABS_API_KEY` or `KIE_API_KEY`, sound, music, stills and B-roll are
motion graphics you design in HyperFrames; say so when you fall back.
Analysis and rendering run on the user's machine; speed depends on its CPU,
ffmpeg and Chrome.

## 5. Gates

Each gate needs the user's yes, in chat, every time:

- Moving files out of `inbox/`.
- Any paid API call. Name the cost first.
- Promoting a style from `styles/drafts/` to `styles/core/`, after one test
  render the user has seen.

The outbox is the end: nothing is published, uploaded, posted or sent.
Raw footage and delivered outbox files stay as they are.

Cut silences first, then cut mistakes on the retimed transcript. One timeline
per stage: original timestamps belong to the original footage only.

Before a draft render run `node scripts/preflight.mjs <project>` and
`npx hyperframes lint`. Review the draft in Studio (browser pane): hero frames,
transition boundaries, audio joins. Record what you saw in `VERIFY.md`.
Visual proof is a reviewed render; lint is a structure check.
