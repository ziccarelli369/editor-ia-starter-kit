# Music

Drop tracks you own the rights to here (mp3 or wav). Royalty-free libraries
work; a song from Spotify does not. One file per track, named
`<mood>-<bpm>-<title>.mp3` when you know the tempo, for example
`punchy-128-night-drive.mp3`.

For a single client, put the tracks in `brands/<slug>/music/` instead.
The agent reads this folder when no music key is set and says which track it used.
Nothing here is committed to git.
