# Generated inserts, music, and SFX

## Generated B-roll and images

Read this section only when the reel uses generated inserts. Kie.ai is the kit's optional provider; use the student's chosen provider or supplied assets. Check the account, credits, and integration before generating; see `docs/TOOLS-AND-API-KEYS.md`, and verify the current official API schema.

- Save the model, prompt, task ID, selected output, and generation state. Reuse a successful job instead of resubmitting.
- Download and inspect the real video files: full-size corners across the selected interval for generated text, logos, malformed hands, or implausible objects. Reframe or regenerate defects, then verify the encoded result. A successful generation is not asset QA.
- B-roll has genuine motion, not a still with a zoom. A static diagram is a source asset only when the final animation transforms it.
- Never generate fake evidence, and never imply a synthetic person is the real named person.

## Music revision

The base levels are in the short-form-edit SKILL.md assembly step. When the user says the music is too loud, reduce its gain relative to the reviewed version and save the measured change. After final normalization, confirm the bed-to-voice ratio is lower; a quieter master alone does not fix it.

## SFX

Build the SFX from the visual-event map. Paper impacts land on object contact, swipes support movement, restrained success tones support checks. Align the audible onset or impact peak, not the start of a file with leading silence. Inspect the actual animation landing before you set each cue.

Score anticipation, contact, and release separately. Vary density and level, keep the voice dominant, and let some cuts pass quietly. A brief bed dip makes the next contact distinct without raising its volume. Record each cue's purpose, and audition transitions when the runtime supports it.

A request for more SFX calls for a richer event score: paper movement, contact, docking, connection, anticipation, and reveal each get a distinct sound. Make meaningful contacts perceptible, vary texture, and keep the quiet conviction beats. Answer it with more varied cues rather than louder music or a whoosh on every cut.
