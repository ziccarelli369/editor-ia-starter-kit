# Spatial open loops

Read this when you choose and build the open loop.

## Pick the shape from the script

| Script shape | The world | What is incomplete |
| --- | --- | --- |
| N parallel items | N sockets on a spine | empty slots (see [wall-of-slots](patterns/wall-of-slots/README.md)) |
| One process, deep | the full pipeline, laid out | a broken or missing link |
| Levels or tiers | a stack that builds upward | the top of the stack is a ghost |
| Comparison | two columns on one shared axis | one column empty, or an unfilled scorecard |
| News or announcement | a timeline, or a landscape map | the right side, the future, is blank |
| Tutorial or build-along | the finished architecture, ghosted | every node not yet built |

## Hand each item to its slot live

Hand an item to its slot with a live camera move of ~1.4s, so the viewer watches
the thing they just learned become the tile; a cut to a pre-made picture of the
filled state loses that. If the video has a numeral or counter, roll it inside
the same move as an odometer, with one start, duration, and ease for both
digits, or they merge into one band mid-roll.

## Name the counter

Pair the corner numeral with a 1-2 word label naming the current item (SUPPORT,
VOICE AI), in the same plate chemistry. Numeral and label move as one rigid
fixture and swap inside the same odometer roll. Nine minutes in, "03" alone
carries nothing: client review of the reference build found the visuals good
and the viewer still lost track of which use case was on screen.
